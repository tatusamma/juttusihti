# Calm UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the Juttusihti desktop app into a calm, reading-first UI — icon rail, feeds dropdown, warm paper & amber theme, four text sizes, three button kinds, AI popover — without removing or changing features.

**Architecture:** A new `style` module owns the two custom Iced themes, the text-size scale, the button/container style functions, the segmented control and the visualisation category colours; every screen switches to it. The left sidebar is replaced by an icon `rail` and a feeds dropdown; the list scope becomes "place (News/Saved) + News scope (all/folder/feed) + unread toggle". The ✨ AI panel and the dropdowns become overlays drawn with `stack!` + `opaque`.

**Tech Stack:** Rust 2024, Iced 0.14 (`canvas`, `tokio`), bundled Lucide icon font (ISC license).

**Spec:** `docs/superpowers/specs/2026-10-31-calm-ui-design.md` — read it first; it is the authority on look and behaviour. Screenshots of the current UI for comparison: retake with the window-capture script described in Task 10.

## Global Constraints

- No new features and no change to data, AI, fetching or analytics behaviour. The only deliberate behaviour change is the Unsubscribe confirmation.
- Keyboard shortcuts unchanged: j/k and ↓/↑, s, m, o/Enter, /, n, p, Ctrl+F, Ctrl+R.
- Dark theme stays the default (`settings::Values::default().dark == true`); the `theme` setting key and its "light" value stay as they are.
- Token values (dark / light): background `#1c1b1a` / `#faf7f2`; pane `#222120` / `#f1ece4`; line `#2f2d2b` / `#e4ddd2`; text `#ebe6df` / `#2a2622`; body `#d6d1c9` / `#3d3832`; muted `#9b958c` / `#7a7268`; faint `#716b64` / `#9a9288`; selection `#2b2926` / `#efe6d8`; accent `#d8a25a` / `#b0702a`. Fine-tune only to meet the contrast tests in Task 1, keeping the warm brown-grey + amber character.
- Amber accent only on: selected article, current rail item, unread dots, Save/saved state, the one main button of a screen. Nothing else in the UI chrome is coloured.
- Four text sizes, none below 12. Secondary text is dimmer, not smaller.
- Three button kinds: main (amber, at most one per screen), quiet (outlined), icon. Destructive actions use quiet + danger colour.
- No literal `.size(<number>)` in view code after Task 9; sizes come from `style` constants.
- Any bundled font must cover ä, ö, å and allow redistribution.
- `cargo fmt`, `cargo clippy --workspace -- -D warnings` and `cargo test --workspace` pass after every task (CI runs these on Windows and Ubuntu 22.04).

## Review Focus

- **First run with no feeds:** the list and dropdown must show a clear "Add a site or feed" entry point (today's sidebar empty-state text), not an empty void. → test in Task 5.
- **Unsubscribing the feed you are viewing:** the News scope must fall back to All feeds, not show an empty list for a deleted feed. → test in Task 5.
- **Closing the AI popover mid-run:** the run must continue and stay reachable (badge on ✨, Pause/Cancel on reopen); a finished run's Review link must not be lost. → tests in Task 7.
- **Light theme readability:** faint and muted text on background and on selection must stay readable. → contrast tests in Task 1.
- **Smallest window (900×560):** rail + list + article must fit without clipping the list headlines or the top bar; long Finnish headlines and feed names wrap or ellipsize. → visual check in Task 10.
